Willkommen

Hier ist die genaue Berechnung und Überprüfung von $E_{\text{kin}}$ sowie der potentiellen Energie $E_{\text{pot}}$ (über die Wellenlänge $\lambda$) an der Skala $R_{\text{min}} = \frac{\hbar}{2 m_e c}$.

Python-Skript zur genauen Berechnung

import scipy.constants as const

# Naturkonstanten aus SciPy (NIST-Werte)
hbar = const.hbar  # Reduziertes Plancksches Wirkungsquantum (J s)
h = const.h        # Plancksches Wirkungsquantum (J s)
m_e = const.m_e    # Elektronenmasse (kg)
c = const.c        # Lichtgeschwindigkeit (m/s)
e = const.e        # Elementarladung (C, für Umrechnung in eV)

# 1. R_min Berechnung
R_min = hbar / (2 * m_e * c)

# 2. Kinetische Energie: E_kin = p^2 / (2 * m_e) mit p = hbar / R_min
p = hbar / R_min
E_kin_J = (p**2) / (2 * m_e)
E_kin_eV = E_kin_J / e
E_kin_MeV = E_kin_eV / 1e6

# 3. Potentielle / Wellen-Energie über die Wellenlänge lambda
# Aus dem HTML-Dokument: lambda_c = 4 * pi * R_min (volle Compton-Wellenlänge)
# oder reduzierte Wellenlänge lambda_bar = 2 * R_min
lambda_c = 4 * const.pi * R_min
lambda_bar = 2 * R_min

# Potentielle Wellen-Energie:
# E_pot (über volle Wellenlänge lambda_c) = h * c / lambda_c
E_pot_lambda_J = (h * c) / lambda_c
E_pot_lambda_MeV = (E_pot_lambda_J / e) / 1e6

# E_pot (über reduzierte Wellenlänge lambda_bar) = hbar * c / lambda_bar
E_pot_bar_J = (hbar * c) / lambda_bar
E_pot_bar_MeV = (E_pot_bar_J / e) / 1e6

# E_pot (direkt über R_min als charakteristische Wellenlänge lambda_bar = R_min)
E_pot_Rmin_J = (hbar * c) / R_min
E_pot_Rmin_MeV = (E_pot_Rmin_J / e) / 1e6

# Ruheenergie der 2-fachen Elektronenmasse: 2 * m_e * c^2
E_ref_J = 2 * m_e * (c**2)
E_ref_MeV = (E_ref_J / e) / 1e6

print(f"R_min = {R_min:.6e} m")
print(f"Referenz 2*m_e*c^2 = {E_ref_MeV:.6f} MeV ({E_ref_J:.6e} J)")
print(f"E_kin = {E_kin_MeV:.6f} MeV")
print(f"E_pot (lambda = R_min) = {E_pot_Rmin_MeV:.6f} MeV")
print(f"E_pot (reduziert lambda_bar = 2*R_min) = {E_pot_bar_MeV:.6f} MeV")
print(f"E_pot (voll lambda_c = 4*pi*R_min) = {E_pot_lambda_MeV:.6f} MeV")

Exakte Ergebnisse der Berechnung

  1. Charakteristischer Radius:

$$R_{\text{min}} = \frac{\hbar}{2 m_e c} \approx 1{,}930796 \times 10^{-13} \text{ m}$$

  1. Ruheenergie-Referenz ($2 m_e c^2$):

$$2 m_e c^2 \approx 1{,}637421 \times 10^{-13} \text{ J} \approx 1{,}021998 \text{ MeV}$$

  1. Kinetische Energie ($E_{\text{kin}}$): Mit $p = \frac{\hbar}{R_{\text{min}}} = 2 m_e c$:

$$E_{\text{kin}} = \frac{p^2}{2 m_e} = \frac{(2 m_e c)^2}{2 m_e} = 2 m_e c^2 \approx 1{,}021998 \text{ MeV}$$

  1. Potentielle / Wellen-Energie ($E_{\text{pot}}$ über Wellenlänge):
  • Fall A (Lokalisierung auf Skala $\bar{\lambda} = R_{\text{min}}$):

$$E_{\text{pot}} = \frac{\hbar c}{R_{\text{min}}} = 2 m_e c^2 \approx 1{,}021998 \text{ MeV}$$

  • Fall B (Reduzierte Compton-Wellenlänge $\bar{\lambda}c = 2 R{\text{min}}$):

$$E_{\text{pot}} = \frac{\hbar c}{\bar{\lambda}c} = \frac{\hbar c}{2 R{\text{min}}} = m_e c^2 \approx 0{,}510999 \text{ MeV}$$

  • Fall C (Volle Compton-Wellenlänge $\lambda_c = 4\pi R_{\text{min}}$):

$$E_{\text{pot}} = \frac{h c}{\lambda_c} = \frac{h c}{4\pi R_{\text{min}}} = m_e c^2 \approx 0{,}510999 \text{ MeV}$$

Überprüfung und Fazit

  • $E_{\text{kin}}$: Die Berechnung aus dem Dokument ist exakt korrekt. Ein Impuls von $p = 2 m_e c$ führt im nicht-relativistischen Ansatz $E_{\text{kin}} = \frac{p^2}{2 m_e}$ exakt auf $E_{\text{kin}} = 2 m_e c^2 \approx 1{,}022 \text{ MeV}$.

  • $E_{\text{pot}}$ über die Wellenlänge:

  • Betrachtet man die Wellenlänge als direkt der Skala $R_{\text{min}}$ zugeordnet ($\bar{\lambda} = R_{\text{min}}$), entspricht $E_{\text{pot}}$ exakt $2 m_e c^2$ ($1{,}022 \text{ MeV}$).

  • Betrachten wir die volle physikalische Compton-Wellenlänge des Elektrons ($\lambda_c = 4\pi R_{\text{min}}$ bzw. $\bar{\lambda}c = 2 R{\text{min}}$), ergibt die Wellenenergie $E = \frac{\hbar c}{\bar{\lambda}_c} = m_e c^2 \approx 0{,}511 \text{ MeV}$ (die exakte Ruheenergie eines einzelnen Elektrons).
