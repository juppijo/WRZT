Wichtige Trigonometrie-Formeln

Formel-Name Formel
GRUNDLEGENDE DEFINITIONEN
Sinus sin(α) = Gegenkathete / Hypotenuse
Kosinus cos(α) = Ankathete / Hypotenuse
Tangens tan(α) = Gegenkathete / Ankathete = sin(α) / cos(α)
Kotangens cot(α) = Ankathete / Gegenkathete = 1 / tan(α) = cos(α) / sin(α)
PYTHAGORÄISCHE IDENTITÄTEN
Hauptidentität sin²(α) + cos²(α) = 1
Tangens-Identität 1 + tan²(α) = 1 / cos²(α)
Kotangens-Identität 1 + cot²(α) = 1 / sin²(α)
ADDITIONSTHEOREME
Sinus-Addition sin(α ± β) = sin(α)cos(β) ± cos(α)sin(β)
Kosinus-Addition cos(α ± β) = cos(α)cos(β) ∓ sin(α)sin(β)
Tangens-Addition tan(α ± β) = (tan(α) ± tan(β)) / (1 ∓ tan(α)tan(β))
DOPPELWINKELFORMELN
Sinus Doppelwinkel sin(2α) = 2sin(α)cos(α)
Kosinus Doppelwinkel (1) cos(2α) = cos²(α) - sin²(α)
Kosinus Doppelwinkel (2) cos(2α) = 2cos²(α) - 1
Kosinus Doppelwinkel (3) cos(2α) = 1 - 2sin²(α)
Tangens Doppelwinkel tan(2α) = 2tan(α) / (1 - tan²(α))
HALBWINKELFORMELN
Sinus Halbwinkel sin(α/2) = ±√((1 - cos(α)) / 2)
Kosinus Halbwinkel cos(α/2) = ±√((1 + cos(α)) / 2)
Tangens Halbwinkel tan(α/2) = sin(α) / (1 + cos(α)) = (1 - cos(α)) / sin(α)
PRODUKTFORMELN
Sinus × Kosinus sin(α)cos(β) = ½[sin(α+β) + sin(α-β)]
Kosinus × Kosinus cos(α)cos(β) = ½[cos(α+β) + cos(α-β)]
Sinus × Sinus sin(α)sin(β) = ½[cos(α-β) - cos(α+β)]
SUMMENFORMELN
Sinus-Summe sin(α) + sin(β) = 2sin((α+β)/2)cos((α-β)/2)
Sinus-Differenz sin(α) - sin(β) = 2cos((α+β)/2)sin((α-β)/2)
Kosinus-Summe cos(α) + cos(β) = 2cos((α+β)/2)cos((α-β)/2)
Kosinus-Differenz cos(α) - cos(β) = -2sin((α+β)/2)sin((α-β)/2)
SINUSSATZ UND KOSINUSSATZ
Sinussatz a/sin(α) = b/sin(β) = c/sin(γ) = 2R
Kosinussatz c² = a² + b² - 2ab·cos(γ)
WICHTIGE WINKELWERTE
sin(0°) = sin(0) 0
sin(30°) = sin(π/6) 1/2
sin(45°) = sin(π/4) √2/2
sin(60°) = sin(π/3) √3/2
sin(90°) = sin(π/2) 1
cos(0°) = cos(0) 1
cos(30°) = cos(π/6) √3/2
cos(45°) = cos(π/4) √2/2
cos(60°) = cos(π/3) 1/2
cos(90°) = cos(π/2) 0
